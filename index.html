01 — Sobre mí

Un poco de contexto

Soy Ingeniero en Informática y Analista Programador, ambos títulos de INACAP. Hice dos prácticas en Softland: la primera analizando y manteniendo sistemas internos en Visual Basic 6, y la segunda desarrollando frontend y backend con C#, Blazor y .NET, con Azure DevOps, GitHub y ceremonias diarias de Scrum.

Antes de eso pasé cuatro años como jefe de turno en Familia MC, cuadrando caja, coordinando personal y llevando el inventario a mano. Cuando después les construí la tienda online, ya sabía exactamente dónde dolía: por eso el pedido sale por WhatsApp y el panel imprime ticket. Es la ventaja rara de haber estado del otro lado del mostrador.

No me caso con un stack. Uso .NET cuando el proyecto pide robustez, Kotlin cuando tiene que andar sin señal, Electron cuando el cliente necesita un instalador y Python cuando hay que sacar datos de donde no los quieren dar. Escribo pensando en quien lea el código después.

Ahora mismo busco un equipo donde seguir creciendo como desarrollador .NET. Si tienes algo entre manos, escríbeme.

02 — Proyectos

Cosas que he construido

Una selección de trabajos recientes. Cada uno resolvió un problema real (o al menos me enseñó algo nuevo).

img/familiamc.jpg

Familia MC — Tienda online

E-commerce completo para una tienda real: catálogo con categorías, búsqueda y filtros, carrito, checkout, envío del pedido por WhatsApp y panel administrativo con gestión de pedidos, estados y ticket de impresión. Desplegado en producción sobre Plesk.

  • .NET 9
  • ASP.NET Core MVC
  • EF Core 9
  • SQL Server
  • Clean Architecture
img/puravision-crm.jpg

PuraVisión — CRM móvil

App Android nativa para la gestión diaria de una óptica. Offline-first: Room es la fuente de verdad y sincroniza contra Firestore, así que la app funciona sin señal. Autenticación con roles de administrador, empleado y optometrista, incluido login offline de reingreso.

  • Kotlin
  • Jetpack Compose
  • Material 3
  • Hilt
  • Room
  • Firebase
img/chanchito.jpg

Chanchito — Finanzas personales

App de presupuesto pensada para gente con ingresos irregulares. Muestra un solo número —cuánto puedes gastar hoy— congelado al abrir el día para que sea un dato en el que confiar. El núcleo son funciones puras sin React ni base de datos, fáciles de testear.

  • React Native
  • Expo
  • TypeScript
  • SQLite
  • Firebase
img/comparador-precios.jpg

Comparador de precios + bot de ofertas

Scraper de cinco tiendas chilenas (Falabella, Tottus, Ripley, Jumbo y Paris) con historial en SQLite y un bot que avisa las ofertas por Telegram. Cada sitio entrega los datos distinto, así que cada tienda tiene su propio adaptador; Ripley hace fingerprinting de TLS y necesitó un cliente HTTP aparte para no comerse un 403.

  • Python
  • Web scraping
  • SQLite
  • Telegram Bot API
img/erp-comida-rapida.jpg

ERP Comida Rápida — Punto de venta

Punto de venta de escritorio para un local de comida rápida, con base de datos local y sin depender de internet. Incluye POS con ticket imprimible, inventario con alertas de stock mínimo, ventas a crédito con abonos, corte de caja, roles de usuario y reportes.

  • Electron
  • JavaScript
  • SQLite
img/controloptica.jpg

ControlÓptica — ERP de operativos

App de escritorio para los operativos de venta de lentes en terreno: se abre la jornada con encargado, sucursal y fecha, y desde ahí se registran clientes, recetas y ventas, con reportes exportables a Excel. Base SQLite local —funciona sin internet en la villa— y empaquetada como instalador de Windows.

  • Electron
  • React 19
  • Vite
  • better-sqlite3
  • ExcelJS

Óptica Puravisión — Sitio web

Sitio corporativo enfocado en captar clientes y transmitir confianza, con formulario de contacto validado y SEO trabajado (robots, sitemap, metadatos). La arquitectura quedó preparada para crecer hacia agenda, inventario e historial clínico sin rehacer el proyecto.

  • .NET 9
  • ASP.NET Core MVC
  • SEO
  • Responsive
